# CleanShed — График уборки в общежитии

PWA-приложение для автоматического составления и управления графиком уборки в блоке общежития. Генерирует справедливое распределение нагрузки между жильцами с учётом личных и общих комнат.

---

## Описание

Приложение предназначено для блоков общежития, где несколько жильцов делят общие помещения (кухня, коридор, ванная) и каждый также отвечает за уборку своей личной комнаты. Система автоматически составляет график на несколько недель вперёд, распределяя нагрузку максимально справедливо.

### Возможности

**Пользовательский интерфейс:**
- Просмотр задач на сегодня с отметкой выполнения
- Полный график уборки, разбитый по неделям
- Статистика уборок за последние 3 месяца
- Адаптивный дизайн, работа на мобильных устройствах
- PWA — установка на домашний экран

**Управление (админ-панель):**
- Добавление, редактирование и удаление жильцов
- Добавление, редактирование и удаление мест уборки
- Назначение доступных личных мест для каждого жильца
- Генерация графика на нужное количество недель
- Просмотр и сброс мастер-пароля

**Алгоритм генерации:**
- Справедливое распределение — кто меньше убирал, тот получает больше задач
- Приоритет для мест, которые убирали реже всего
- Личные комнаты назначаются только их владельцам
- Общие комнаты распределяются между всеми жильцами
- Учёт статистики за предыдущие периоды

## Установка и запуск

### Быстрый старт

```bash
# Клонирование репозитория
git clone <repository-url>
cd cleanshed

# Запуск (первый раз скачает зависимости)
./gradlew bootRun
```

Приложение будет доступно по адресу: **http://localhost:8080**

### Сборка JAR

```bash
# Сборка
./gradlew bootJar

# Запуск JAR
java -jar build/libs/cleanshed-1.0.0.jar
```

### Запуск с настройками через переменные окружения

```bash
# Указать путь к базе данных
DB_PATH=/var/data/cleanshed.db ./gradlew bootRun

# Указать порт
PORT=3000 ./gradlew bootRun

# Все параметры вместе
DB_PATH=/var/data/cleanshed.db PORT=3000 ./gradlew bootRun
```

## Как работает генерация графика

1. Админ выбирает день недели и количество недель
2. Система берёт всех активных жильцов и все места (личные + общие)
3. Для каждой недели:
   - Места сортируются по количеству уборок (меньше = выше приоритет)
   - Для каждого места выбирается жилец с наименьшей нагрузкой
   - Личные комнаты доступны только их владельцам
   - Общие комнаты доступны всем
4. Статистика обновляется для корректного распределения на следующей неделе
